自媒体工作台

这是 DeepSeek Harness 的一个插件。装上以后，侧栏里会多一个页面：你在里面记灵感，它帮你把一条灵感写成脚本，再配上标题、封面、配图和分镜。

安装：复制这一行，粘到终端里回车
$ dsh plugin --profile desktop add dsh-media-desk

不想用终端的话，下面还有另外两种安装方法。

此页介绍原作者版本。winter fork 使用原生会话与 Notes，安装请阅读 winter fork 说明。

怎么安装

一共三种方法，装出来是一样的。需要 DeepSeek Harness 0.2.1-rc.5 及以上的 0.2.x 版本。

1

方法一：用 npm 安装推荐

在终端里跑一行命令。以后要更新，重跑这一行就行。

  1. 先把 DeepSeek Harness 完全退出（按 ⌘Q）。打开终端。
  2. 在终端里粘贴这一行，回车：
    $ dsh plugin --profile desktop add dsh-media-desk
  3. 重新打开 DeepSeek Harness，侧栏里就有「自媒体工作台」了。重新启动 dsh web，侧栏里就有「自媒体工作台」了。
不用终端：在 DeepSeek Harness 的插件页里安装

打开 DeepSeek Harness 侧栏的「插件」→「添加插件」，输入包名 dsh-media-desk，点安装。

或者把下面这条索引地址加到「发现」里（要先在「实验性插件」里打开「自定义插件索引」），之后在列表里点安装，更新也是点一下：

https://raw.githubusercontent.com/woniuniuniu/dsh-media-desk/main/index.json
2

方法二：把 GitHub 链接发给 DeepSeek Harness

让它自己读安装说明，替你装。

  1. 在 DeepSeek Harness 里开一个新会话。
  2. 把这句话发给它：

    帮我安装这个插件：https://github.com/woniuniuniu/dsh-media-desk

  3. 等它装完，按它说的重启 DeepSeek Harness。
3

方法三：下载安装包再装

适合连不上 npm 的情况。

  1. 下载最新的安装包（一个 .tgz 文件），放到一个以后不会动的文件夹里。
    去下载安装包 →
  2. 在终端里进到那个文件夹，粘贴这一行，回车（桌面版同样要先 ⌘Q 退出）：
    $ dsh plugin --profile desktop add "file:$PWD/dsh-media-desk-2.7.2.tgz"
  3. 重新打开 DeepSeek Harness。重新启动 dsh web。
可能遇到的问题
  • 终端说找不到 dsh：在桌面版的菜单里选「管理 dsh 命令」，注册一下再试。
  • 想卸载：把命令里的 add 换成 remove。你的内容一直存在 ~/.dsh/media-desk/，不会跟着删。

装好以后是什么样

侧栏里会多一个「自媒体工作台」，里面有五个页面。第一次打开看到的是示例内容，右上角可以清空。

成稿

把一条灵感写成一篇稿子

点开一条灵感，点「一键成稿」，它会写出标题和脚本，画出封面、配图和六格分镜。哪里不满意，在左边打字告诉它，右边就会改；改错了可以撤销。

灵感

记灵感的地方

文字、链接、图片、视频都可以贴进来，每条是一张卡片。记新灵感的时候，以前内容相近的卡片会排到它旁边。

排期

安排哪天发

写好的稿子拖到日历上的某一天，就排好了。右上角显示下一条要发的是哪篇。

复盘

发完看数据

把播放、点赞这些数据录进来（手动填、贴表格，或者导入自己的账号），能看到趋势和哪篇表现最好。它给的建议可以存成写作规则，以后写稿会照着来。

风格

选写稿的风格

有 15 种现成的博主风格可以选。也可以贴几篇自己写过的稿子，让它学你的写法。

要花钱吗

插件免费。但写稿和画图要用到模型，用的是你自己的账号和额度。

写脚本

用的是你在 DeepSeek Harness 里已经配好的模型。

画封面和配图

要填你自己的生图密钥，或者用 DSH 里已有的订阅生图。不配也能用，只是封面上只有文字。

你的内容

都存在你自己的电脑上，不上传，也不用注册账号。

不想自己配模型的话，可以用博主农场

博主农场是我们做的网站，写稿和画图的模型都已经配好了，打开网页就能用。
