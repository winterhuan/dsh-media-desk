# 排期、指标与复盘

排期记录作品、平台和带时区的时间，采用用户所在时区。区分待发布与实际发布；排上日历不等于已向平台发布。

指标保留日期、平台、阅读和互动数据，明确关联作品与统计范围。无法关联作品的数据只支持平台观察。区分累计与增量，不能把重复累计快照当新增表现相加。

导入 CSV 时使用 UTF-8，保留表头、有效行、错误行及原因。平台汇总不自动关联某件作品；示例数据不混入真实复盘。

复盘说明分母、时间范围和缺项，再结合具体作品的选题、开头、结构与修改解释观察。指标不能证明某条写作规则导致高阅读。有依据的结论进入 learning 流程成为待审规则；证据不足可以不提出新规则。

账号记录保存平台、handle、网址和公开信息；当前不自动登录采集账号，也不提供逐帖实时指标。排期和指标的当前可写位置以文件协议为准，不能把报告文件称为已更新工作台状态。
