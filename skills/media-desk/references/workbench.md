# 灵感、材料与内容管理

已有作品先读取当前文件与身份。相同链接或材料先检查是否已收藏；标题不能代替作品身份。

收藏笔记、引用、网页、图片或视频时保留标题、原文、来源、链接、语言与标签。区分完整正文、摘录和简介，记录读取日期；保存链接不等于已读全文。附件保留原文件及其与选题的关系。

从材料形成选题时写清要讨论的问题、读者、证据和创作角度。人物、角色、语言习惯和相关作品可以帮助延续创作，不替用户虚构人物经历。

内容生命周期为灵感、大纲、草稿、待发布、已发布。查看或整理作品时以标题、身份、状态、平台和排期展示，支持标签、分类和相关作品关系。收藏材料与正式正文分开，不能把每个收藏页自动改造成文章。

文风由用户选定的风格和个人语气共同提供；规则学习按 learning 流程执行。修改内容文件后校验身份、格式和来源；删除或解除关联前核对目标。
